Driver responsibility: road signs, traffic lights, temporary traffic management and current conditions always take priority over this software. Do not use or hold the phone while driving. Use only hands-free in a secure mount that does not obstruct the road view.

Speed limits shown by map data are advisory to the system only. If confidence is low, the display says CHECK SIGN. The app never treats an uncertain map value as legally authoritative.

The build uses OpenStreetMap, OSRM, Nominatim and Overpass. Network services can be unavailable or stale. Fail-safe behaviour is to retain navigation where possible and avoid inventing missing road data.

MUK SATNAV 86 — Safety First

Hands-free navigation assistance only.

UK rules require proper control of the vehicle. Do not hold or use a phone or similar device while driving. Navigation screens can distract; if you need to interact with the device, stop somewhere safe. Road signs and signals always override the app.

This software is not an approved or certified vehicle safety system. GPS, map, routing, speed-limit and hazard data can be wrong, missing or delayed.
